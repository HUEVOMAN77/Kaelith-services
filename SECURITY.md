# Security Policy

## Reporting a Vulnerability

We take the security and privacy of **HCS** users extremely seriously.

If you discover a security vulnerability or privacy flaw in HCS:
1. **Do NOT open a public GitHub issue.**
2. Send a detailed report to the HCS security maintainers.
3. Include steps to reproduce, affected modules, and potential impact.

## Non-Negotiable Security Rules
- HCS will **never** collect passwords, Google tokens, IMEIs, MAC addresses, or personal logs.
- HCS does not implement root evasion, Play Integrity bypasses, or banking security bypasses.
- All exported logs are sanitized locally before user export.
